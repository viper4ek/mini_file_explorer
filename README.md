## 🌟 Основні можливості

### 🧭 Навігація та Швидкий доступ
- **Історія переходів:** Повноцінна навігація «Назад» ⬅ та «Вперед» ➡ із збереженням стека історій, а також кнопка перехода на рівень вгору ⬆.
- **Пряме введення шляху:** Текстовий адресний рядок із можливістю швидкого переходу за клавішею `Enter`.
- **Бічна панель (Quick Access):** Моментальний доступ до основних папок користувача (*Робочий стіл, Документи, Завантаження, Зображення, Музика, Відео*) та системних дисків (`C:`, `D:` тощо).

### 📄 Керування файлами та Операції
- **Створення об'єктів:** Швидке створення нових папок та документів стандартних типів (`.txt`, `.docx`, `.xlsx`, `.zip`).
- **Буфер обміну (Clipboard):** Підтримка копіювання (`Ctrl + C`), вирізання (`Ctrl + X`) та вставляння (`Ctrl + V`) як поодиноких файлів, так і групи об'єктів.
- **Безпечне перейменування:** 
  - Попередження при зміні або видаленні розширення файлу (захист від випадкового псування даних).
  - Валідація назв на наявність заборонених системних символів (`\ / : * ? " < > |`).
- **Групове видалення:** Видалення вибраних об'єктів із обов'язковим підтвердженням дії користувачем.
- **Відкриття у системах:** Подвійний клік на файл відкриває його у стандартній програмі операційної системи.

### 🔎 Пошук та Сортування
- **Інтерактивне сортування:** Клік по заголовках колонки (*Ім'я, Тип, Розмір, Дата зміни*) змінює порядок сортування (за зростанням / спаданням). Незалежна зміна ширини колонок без викривлення суміжних.
- **Живий фільтр:** Миттєва фільтрація вмісту поточної директорії під час введення тексту.
- **Рекурсивний пошук:** Можливість глибокого пошуку файлів у всіх підпапках поточного дерева із захистом від переповнення пам'яті.

### 👁 Панель попереднього перегляду (Preview Pane)
- Динамічний перегляд тексту та коду (файли `.txt`, `.py`, `.json`, `.md`, `.html`, `.css` тощо розміром до 15 КБ).
- Захист вмісту від випадкового редагування.
- Повна підтримка виділення тексту мишею, копіювання через `Ctrl + C` та контекстного меню ПКМ («Скопіювати», «Виділити все»).

### 🎨 Кастомізація та Дизайн
- **Перемикання тем "на льоту":** Зручні кнопки вгорі панелі для миттєвої зміни інтерфейсу між **Dark Mode** 🌙 (темна VS Code тема) та **Light Mode** ☀️ (класична світла тема).
- **Сучасні шрифти та стилі:** Адаптований графічний дизайн із використанням шрифтів `Segoe UI` та `Consolas`.
- **Множинний вибір:** Підтримка затискання `Ctrl + ЛКМ` та `Shift + ЛКМ` для виділення декількох файлів із захистом від випадкового групового перейменування чи відкриття.

## 🎹 Гарячі клавіші (Shortcuts)

| Комбінація | Дія |
| :--- | :--- |
| `Ctrl + C` | Копіювати виділені об'єкти в буфер обміну |
| `Ctrl + X` | Вирізати виділені об'єкти в буфер обміну |
| `Ctrl + V` | Вставити об'єкти з буфера обміну в поточну папку |
| `Delete` | Видалити виділені об'єкти |
| `Alt + ⬅` | Навігація «Назад» по історії |
| `Alt + ➡` | Навігація «Вперед» по історії |
| `Enter` | Перехід за адресою / Відкриття файлу чи папки |
| `Shift + ЛКМ` | Виділити діапазон файлів |
| `Ctrl + ЛКМ` | Виділити декілька окремих файлів |

## 🏗 Структура проєкту

Проєкт побудовано за модульною архітектурою з чітким розділенням інтерфейсу та бізнес-логіки:

```text
mini_file_explorer/
│
├── core/
│   └── file_system.py      # Логіка файлової системи (читання, пошук, буфер, перейменування)
│
├── ui/
│   ├── main_window.py      # Головне вікно Tkinter, віджети, теми та обробка подій
│   └── context_menus.py    # Контекстні меню правої кнопки миші (ПКМ)
│
├── main.py                 # Точка входу в програму
├── README.md               # Документація проєкту
└── .gitignore              # Файл виключення непотрібних збірок для Git
```

## 🚀 Інструкція із запуску

### Запуск із вихідного коду (Python)

1. Переконайтеся, що на комп'ютері встановлено **Python 3.8+**.
2. Клонуйте репозиторій:
   ```bash
   git clone https://github.com/viper4ek/mini_file_explorer.git
   ```
3. Перейдіть у папку проєкту:
   ```bash
   cd mini_file_explorer
   ```
4. Запустіть головний файл:
   ```bash
   python main.py
   ```

## 📦 Компіляція в автономний `.exe` файл

Ви можете зібрати програму в один виконуваний файл, який працюватиме на ПК без встановленого Python:

1. Встановіть `PyInstaller`:
   ```bash
   pip install pyinstaller
   ```
2. Виконайте команду збірки у терміналі проєкту:
   ```bash
   pyinstaller --noconsole --onefile main.py
   ```
3. Готовий файл з'явиться за шляхом: **`dist/main.exe`**.

Програма розроблена з урахуванням захисту від збоїв файлової системи:
