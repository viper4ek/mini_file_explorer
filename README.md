# 📁 Mini File Explorer

Легкий, швидкий та зручний аналог провідника Windows, написаний на Python з використанням бібліотеки **Tkinter** (`ttk`). Проєкт розроблений як повнофункціональний десктопний застосунок для зручної навігації файловою системою, керування файлами та перегляду їхнього вмісту.

---

## ✨ Основні можливості

- **Навігація та історія:** Повна підтримка переходу в папки, кнопка «Вгору», а також історія навігації «Назад» і «Вперед» (`Alt + Left` / `Alt + Right`).
- **Швидкий доступ (Sidebar):** Швидкий перехід до системних дисків (`C:`, `D:`) та стандартних папок користувача (Робочий стіл, Документи, Завантаження тощо).
- **Файлові операції:** 
  - Створення папок та документів (`.txt`, `.docx`, `.xlsx`, `.zip`).
  - Копіювання (`Ctrl + C`), вирізання (`Ctrl + X`), вставлення (`Ctrl + V`) та видалення (`Delete`) як по одному, так і кількох елементів (`Shift` / `Ctrl` + клік).
  - Перейменування з інтелектуальним захистом розширень файлів.
  - Заборона використання недопустимих системних символів (`\ / : * ? " < > |`).
- **Сортування та пошук:** 
  - Інтерактивне сортування за назвою, типом, розміром та датою зміни.
  - Живий пошук поточної папки з можливістю рекурсивного обходу підпапок (`os.walk`).
- **Панель попереднього перегляду (Preview Pane):** Швидкий перегляд вмісту текстових файлів та коду до 15 КБ прямо в інтерфейсі з можливістю виділення та копіювання тексту.
- **Теми оформлення:** Миттєве перемикання між Темною (`🌙`) та Світлою (`☀️`) темами "на льоту".

---

## 🛠 Технології

- **Python 3.x**
- **Tkinter / ttk** (Графічний інтерфейс користувача)
- **Pathlib, Shutil, OS, Zipfile** (Робота з файловою системою)
